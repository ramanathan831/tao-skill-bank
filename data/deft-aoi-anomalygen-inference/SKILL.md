# Cosmos AnomalyGen SDG Pipeline

You are helping the user run the complete AnomalyGen Synthetic Data Generation
pipeline. It has three sequential steps:

1. **Step 1 — Automatic Mask Placement (AMP):** Place defect submask templates
   onto clean images using per-image ROI masks.
2. **Step 2 — Prepare sdg_inference.jsonl:** Pair clean images with auto-placed
   masks and SDG generation parameters.
3. **Step 3 — SDG Inference:** Generate synthetic anomaly images using the
   pretrained AnomalyGen model.

**Runtime environment (local Docker):**
- Container image: `nvcr.io/nvidian/iva/anomalygen_light:computex20260325`
- All pipeline steps execute inside this container via `docker exec`

> **IMPORTANT:** All data and checkpoint paths are local host directories
> mounted into the container via `-v`. Commands inside the container reference
> container paths, not host paths.

## Known Workarounds (apply proactively)

These three issues occur on every run. Apply them **before** they cause errors:

### 1. ag_config.yaml trimming

The AG checkpoint's `ag_config.yaml` contains training-only keys (`scheduler`,
`optimizer`, `trainer`, `job`) that cause `OmegaConf` / `set_nested_attributes`
errors during inference. **Fix:** Create a wrapper checkpoint directory that
symlinks all files from the original checkpoint, then replace `ag_config.yaml`
with a trimmed version containing only the `model` section:

```bash
# Create wrapper dir
mkdir -p <sdg_output>/ag_ckpt_wrapper
ln -s <checkpoint_path>/checkpoints <sdg_output>/ag_ckpt_wrapper/checkpoints
ln -s <checkpoint_path>/config.yaml <sdg_output>/ag_ckpt_wrapper/config.yaml
# ... symlink everything EXCEPT ag_config.yaml

# Extract model-only config
python3 -c "
import yaml
with open('<checkpoint_path>/ag_config.yaml') as f:
    cfg = yaml.safe_load(f)
with open('<sdg_output>/ag_ckpt_wrapper/ag_config.yaml', 'w') as f:
    yaml.dump({'model': cfg['model']}, f)
"
```

Then pass the wrapper dir as `--ag_checkpoint_dir` instead of the original.

### 2. AMP mask sizing

AMP defaults to submask dimensions, **not** clean image dimensions. Clean images
may have different sizes. Always pass `--image_size W H` per ROI file, getting
dimensions from the corresponding clean image:

```bash
img_size=$(python3 -c "from PIL import Image; w,h=Image.open('${clean_img}').size; print(w,h)")
img_w=$(echo "${img_size}" | cut -d' ' -f1)
img_h=$(echo "${img_size}" | cut -d' ' -f2)
```

Without this, masks will have wrong dimensions and SDG inference will fail with
an image/mask size mismatch error.

### 3. HF_TOKEN may not be available

If `HF_TOKEN` is not set on the host and the pretrained models (Cosmos Predict2,
NVDINOV2, C-RADIO-V3) are already downloaded and mounted at the container's
`checkpoints/` path, **skip the HF login step entirely**. The token is only
needed for downloading gated models — not for inference.

## Step 1: Automatic Mask Placement (AMP)

For each active defect type, place submask templates onto clean images using
per-image ROI masks with seed variation.

### How it works

- Each clean image in `<clean_image_dir>/<defect>/` has a corresponding ROI
  mask in `<roi_dir>/<defect>/` matched by **filename stem** (same name,
  extension may differ).
- A submask template is randomly selected from `<submask_dir>/<defect>/`.
- AMP places the submask within the ROI region, generating `N` different
  placements via `--seed_range 1 <N>`.
- The clean image is only read to determine its pixel dimensions (`--image_size`).

### Command Pattern

Write the AMP script to a temp file on the host, copy it into the container,
and execute it. Repeat **for each active defect type**:

```bash
cat > /tmp/run_amp.sh << 'SHEOF'
#!/bin/sh
DEFECT="<defect>"
SUBMASK_DIR="/data/submask_dir/${DEFECT}"
ROI_DIR="/data/roi_dir/${DEFECT}"
CLEAN_DIR="/data/clean_image_dir/${DEFECT}"
AMP_OUTPUT="/data/amp_output/${DEFECT}"
N=<N>

SUBMASK=$(ls "${SUBMASK_DIR}"/*.jpg "${SUBMASK_DIR}"/*.png 2>/dev/null | shuf -n 1)

if [ -z "${SUBMASK}" ]; then
    echo "WARNING: No submask files in ${SUBMASK_DIR}. Skipping ${DEFECT}."
    exit 1
fi

echo "=== AMP: defect=${DEFECT}, submask=$(basename ${SUBMASK}), N=${N} ==="

for roi_file in "${ROI_DIR}"/*.png "${ROI_DIR}"/*.jpg; do
    [ -f "${roi_file}" ] || continue
    roi_stem=$(basename "${roi_file}")
    roi_stem="${roi_stem%.*}"

    clean_img=""
    for ext in jpg png jpeg; do
        if [ -f "${CLEAN_DIR}/${roi_stem}.${ext}" ]; then
            clean_img="${CLEAN_DIR}/${roi_stem}.${ext}"
            break
        fi
    done

    if [ -z "${clean_img}" ]; then
        echo "WARNING: No clean image for ROI ${roi_stem}. Skipping."
        continue
    fi

    img_size=$(python3 -c "from PIL import Image; w,h=Image.open('${clean_img}').size; print(w,h)")
    img_w=$(echo "${img_size}" | cut -d' ' -f1)
    img_h=$(echo "${img_size}" | cut -d' ' -f2)

    out_dir="${AMP_OUTPUT}/${roi_stem}"
    echo "  Processing: ${roi_stem} (${img_w}x${img_h}, seeds 1..${N})"

    python3 -m scripts.anomaly_gen.automatic_mask_placement \
        --submask "${SUBMASK}" \
        --roi_image "${roi_file}" \
        --n 1 \
        --seed_range 1 ${N} \
        --output_base_dir "${out_dir}" \
        --image_size ${img_w} ${img_h}
done

echo "=== AMP complete for ${DEFECT}. Output: ${AMP_OUTPUT} ==="
SHEOF

docker cp /tmp/run_amp.sh anomalygen-worker:/tmp/run_amp.sh
docker exec anomalygen-worker sh /tmp/run_amp.sh
```

### AMP Output Structure

```

    └── <image_stem>/
        ├── seed_0001/
        │   └── auto_placed_mask_with_1_rois_seed_1.png

        │   └── auto_placed_mask_with_1_rois_seed_2.png

```

## Step 2: Prepare sdg_inference.jsonl

Generate a JSONL file pairing each clean image with its auto-placed masks and
SDG generation parameters.

> **CRITICAL:** All paths in the JSONL must be **container paths** (e.g.,
> `/data/clean_image_dir/bridge/image_A.jpg`), since Step 3 reads them inside
> the same container.

### Spatial Dependency Rules

Read `defect_description.jsonl` to determine each defect's spatial dependency:

| Spatial Dependency | `shift_values` | `rotation_angle` | `morph_operation` |
|---|---|---|---|
| `position_dependent` | `"0,0"` | `0` | `"none"` |
| `free` | random x,y each in [-100, 100] | random in [0, 180] | random from `dilate`, `open`, `close`, `none` |

### JSONL Entry Format

Each line is a JSON object with these fields (matches
`scripts/anomaly_gen/create_testcase.py` format):

```json
{
  "image_filename": "/data/clean_image_dir/bridge/image_A.jpg",
  "mask_filename": "/data/amp_output/bridge/image_A/seed_0001/auto_placed_mask_with_1_rois_seed_1.png",
  "anomaly_type": "PCB+bridge",
  "guidance": 7.0,
  "num_steps": 35,
  "crop_and_paste": true,
  "crop_ratio": 2.0,
  "crop_grid_X": "none",
  "crop_grid_Y": "none",
  "num_generated_images": 1,
  "poisson_blend": false,
  "shift_values": "0,0",
  "rotation_angle": 0,
  "morph_operation": "none",
  "iteration_generation_max_instance": 5
}
```

### Generation Script

Write a Python script to a temp file, copy it into the container, and execute:

```bash
cat > /tmp/gen_jsonl.py << 'PYEOF'
import json, os, glob, secrets

CLEAN_IMAGE_DIR = "/data/clean_image_dir"
AMP_OUTPUT_DIR = "/data/amp_output"
DEFECT_DESC_PATH = "/data/defect_description.jsonl"
OUTPUT_JSONL = "/data/output/sdg_inference.jsonl"
ACTIVE_DEFECTS = [<list of active defect short names>]  # e.g., ["bridge"]

defect_info = {}
with open(DEFECT_DESC_PATH) as f:
    for line in f:
        entry = json.loads(line.strip())
        full_type = entry["defect_type"]
        short_name = full_type.split("+")[1]
        defect_info[short_name] = {
            "anomaly_type": full_type,
            "position_dependent": entry["spatial_dependency"] == "position_dependent"
        }

GUIDANCE_OPTIONS = [1.5, 5.0, 7.0]

os.makedirs(os.path.dirname(OUTPUT_JSONL), exist_ok=True)
count = 0

with open(OUTPUT_JSONL, "w") as fp:
    for defect in ACTIVE_DEFECTS:
        info = defect_info.get(defect)
        if info is None:
            print(f"WARNING: {defect} not in defect_description.jsonl. "
                  f"Defaulting to position_dependent.")
            info = {"anomaly_type": f"UNKNOWN+{defect}",
                    "position_dependent": True}

        amp_defect_dir = os.path.join(AMP_OUTPUT_DIR, defect)
        if not os.path.isdir(amp_defect_dir):
            print(f"WARNING: No AMP output for {defect}. Skipping.")
            continue

        for image_stem in sorted(os.listdir(amp_defect_dir)):
            stem_dir = os.path.join(amp_defect_dir, image_stem)
            if not os.path.isdir(stem_dir):
                continue

            clean_img = None
            for ext in ["jpg", "png", "jpeg"]:
                p = os.path.join(CLEAN_IMAGE_DIR, defect, f"{image_stem}.{ext}")
                if os.path.exists(p):
                    clean_img = p
                    break
            if not clean_img:
                print(f"WARNING: No clean image for {image_stem}. Skipping.")
                continue

            for seed_name in sorted(os.listdir(stem_dir)):
                seed_dir = os.path.join(stem_dir, seed_name)
                if not os.path.isdir(seed_dir):
                    continue

                masks = glob.glob(os.path.join(seed_dir,
                                               "auto_placed_mask_*.png"))
                if not masks:
                    continue
                mask_path = masks[0]

                if info["position_dependent"]:
                    shift_values = "0,0"
                    rotation_angle = 0
                    morph_operation = "none"
                else:
                    sx = secrets.randbelow(201) - 100
                    sy = secrets.randbelow(201) - 100
                    shift_values = f"{sx},{sy}"
                    rotation_angle = secrets.randbelow(181)
                    morph_operation = secrets.choice(
                        ["dilate", "open", "close", "none"])

                data = {
                    "image_filename": clean_img,
                    "mask_filename": mask_path,
                    "anomaly_type": info["anomaly_type"],
                    "guidance": secrets.choice(GUIDANCE_OPTIONS),
                    "num_steps": 35,
                    "crop_and_paste": True,
                    "crop_ratio": 2.0,
                    "crop_grid_X": "none",
                    "crop_grid_Y": "none",
                    "num_generated_images": 1,
                    "poisson_blend": False,
                    "shift_values": shift_values,
                    "rotation_angle": rotation_angle,
                    "morph_operation": morph_operation,
                    "iteration_generation_max_instance": 5
                }
                fp.write(json.dumps(data) + "\n")
                count += 1

print(f"Generated {count} entries in {OUTPUT_JSONL}")
PYEOF

docker cp /tmp/gen_jsonl.py anomalygen-worker:/tmp/gen_jsonl.py
docker exec anomalygen-worker python3 /tmp/gen_jsonl.py
```

## Known Issues & Error Handling

### Container Shell Compatibility

The container's `/bin/sh` is POSIX `sh`, **not bash**. Avoid bash-isms:

| Bash-ism | POSIX Alternative |
|----------|-------------------|
| `read a b <<< "$var"` | `a=$(echo "$var" \| cut -d' ' -f1)` |
| `[[ ... ]]` | `[ ... ]` |
| `${var,,}` (lowercase) | `echo "$var" \| tr 'A-Z' 'a-z'` |
| `$'...'` (ANSI-C quoting) | Use `printf` or plain quotes |

All scripts written to `/tmp/*.sh` **must** use `#!/bin/sh` and POSIX syntax
only. Never use `#!/bin/bash`.

### Missing Pretrained Models (FileNotFoundError)

The SDG pipeline loads multiple pretrained models at hardcoded relative paths
under `checkpoints/` inside the container. If any is missing, the pipeline
crashes with `FileNotFoundError`. The code loads them sequentially, so you'll
only see one error at a time — fix one, hit the next.

| Model | Path | Source |
|-------|------|--------|
| Cosmos Predict2 | `checkpoints/nvidia/Cosmos-Predict2-2B-Text2Image/` | HuggingFace (gated) |
| NV-DINOv2 | `checkpoints/NVDINOV2/nv_dinov2_classification_model.ckpt` | NGC |
| C-RADIOv3-B | `checkpoints/nvidia/C-RADIO-V3/model.safetensors` | HuggingFace |
| T5-11B (transitive) | `checkpoints/google-t5/t5-11b/` | HuggingFace (auto-downloaded) |

**Solution:** Mount `<pretrained_checkpoints_dir>` at the container's
`checkpoints/` path and run the built-in download script:

```bash
docker exec anomalygen-worker sh -c "
    huggingface-cli login --token \${HF_TOKEN}
    python -m scripts.download_checkpoints --model_types text2image --model_sizes 2B
"
```

The script is idempotent and handles all dependencies. If it fails, see the
manual download links in the "Download Pretrained Models" section.

> **DO NOT** download models file-by-file. Use the download script — it knows
> the full dependency tree.

### HF_TOKEN (401 Unauthorized)

`nvidia/Cosmos-Predict2-2B-Text2Image` is a **gated repo** — download fails
with `401 Unauthorized` without a valid `HF_TOKEN`.

**HF_TOKEN resolution order** (check on the **host** before anything else):

1. `$HF_TOKEN` environment variable (already exported)
2. `.env` file in project root (`HF_TOKEN=hf_...`)
3. `~/.bashrc` or `~/.bash_profile` (grep for `HF_TOKEN=`)
4. `~/.cache/huggingface/token` (written by `huggingface-cli login`)

> **Common gotcha:** Users often put `HF_TOKEN=hf_...` in `~/.bashrc` without
> `export`. Non-interactive shells (AI agents, cron, scripts) never source
> `.bashrc`, so `$HF_TOKEN` appears empty. The resolution logic above handles
> this by grep-ing the file directly.

> **DO NOT** waste time searching for the token inside the container, running
> `find`, or grepping random env vars. If none of the four sources above have
> it, **stop immediately** and ask the user to provide `HF_TOKEN`.

### Long-Running Steps (AMP & SDG Inference)

**Step 1 — AMP:** Can take several minutes depending on image count and `N`
(seed count). For 5 images × 5 seeds, expect ~3-5 minutes. Set timeout to at
least **10 minutes**. Do **not** kill early — partial AMP output causes missing
entries in the JSONL.

**Step 3 — SDG Inference:** This is the heaviest step. The diffusion model
generates images one by one on GPU. For 25 entries (5 images × 5 seeds),
expect **~30 minutes**. Set timeout to at least **45 minutes** or run in
background mode. Monitor progress via container logs:

```bash
docker logs -f anomalygen-worker
```

If using an AI agent runner, use background execution and poll periodically
rather than blocking. Do **not** kill the process — the model writes results
incrementally and a partial run still produces usable output in
`<output_dir>/reconstructed_image/`.

### Pipeline Errors

- **Missing ROI or submask directory for a defect**: Print a warning and skip
  that defect. **Never** fall back to the `mask/` directory.
- **Unsupported anomaly type**: Stop execution and show the user which anomaly
  types the checkpoint supports.
- **No matching clean image for a ROI**: Skip that ROI file with a warning.
- **No active defects after validation**: Stop and inform the user that no
  defects passed validation.
- **Non-binary masks**: The SDG pipeline raises `ValueError` if mask pixel
  values are not strictly 0 or 255.
- **Duplicate JSONL entries**: Each image-mask pair must be unique within the
  JSONL file.

### Docker Errors

- **Docker image not found**: Pull with `docker pull nvcr.io/nvidian/iva/anomalygen_light:computex20260325`.
- **Container already exists**: Stop and remove first: `docker stop anomalygen-worker && docker rm anomalygen-worker`.
- **GPU not available in container**: Ensure `--gpus all` is passed and NVIDIA Container Toolkit is installed.
- **Permission errors on mounted volumes**: Check that host directories are
  readable. Output dirs may be owned by the container user — write intermediate
  files to `/tmp` inside the container if needed.
